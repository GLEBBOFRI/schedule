## 🔑 1. Как получить `ITMO_TOKEN` в браузере

Токен авторизации нужен, чтобы скрипт делал запросы к API ИТМО от твоего имени.

> **⚠️ ВАЖНО:** Никогда не публикуй свой токен в открытых репозиториях и не добавляй его прямо в код!

1. Открой браузер и войди в [ИСУ ИТМО](https://isu.ifmo.ru) или [my.itmo.ru](https://my.itmo.ru).
2. Открой **Инструменты разработчика** (DevTools):
   - Нажми **F12** (или `Cmd + Option + I` на macOS).
3. Перейди во вкладку **Network** (Сеть).
4. В строке поиска/фильтра введи `api` или `schedule`.
5. Перезагрузи страницу (**F5** или `Cmd + R`).
6. Кликни на любой успешный запрос к API в списке.
7. В правой панели перейди в раздел **Headers** $\rightarrow$ **Request Headers** (Заголовки запроса).
8. Найди строку `Authorization:`.
9. Скопируй всю длинную строку **после слова `Bearer `** (начинается с `ey...`). Это и есть твой токен.
